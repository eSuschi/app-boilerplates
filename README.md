# app-boilerplates

Reusable boilerplates and architecture starters for applications, desktop tools and modular systems.

## Purpose
Clean, opinionated starting points for real applications – from simple tools to more complex modular systems and local desktop apps.

## Planned content
- Web app foundations (frontend + backend patterns)
- Desktop application starters (e.g. Tauri / Electron oriented)
- Modular engine / system architecture templates
- AI-assisted application scaffolds

## Guiding principles
- Clear separation of concerns
- Strong typing and maintainability where applicable
- Easy to audit and extend
- Ready for professional release process

This repository grows together with actual projects.
